# Unity Body Catcher

An interactive body-tracking game built with Unity and MediaPipe, where the player's body becomes the controller.

> **Project goal:** Create a fast, polished prototype that demonstrates Unity, real-time body tracking, interaction design, and creative technology for interactive experiences.

## Concept

Players stand in front of a webcam and use their body to catch falling objects. The game is designed for hands-free interaction and can be adapted for exhibitions, installations, events, and interactive experiences.

## Planned Features

- Real-time body/pose tracking with MediaPipe
- Webcam-based interaction
- Hand and body landmark detection
- Falling collectible objects
- Score and combo system
- Increasing difficulty
- Particle and visual feedback
- Simple onboarding for first-time players
- Desktop build for interactive installation use

## Technology

- MediaPipe
- Webcam / camera input
